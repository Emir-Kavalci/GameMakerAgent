PASS if the spec has at least three acceptance criteria that a person could check by playing the game in the editor (each describes an observable result), gives concrete starting values for anything tunable, and contains no C++ or Blueprint implementation code.
FAIL if acceptance criteria are missing or vague ("works well", "feels good"), or the document contains implementation code.
