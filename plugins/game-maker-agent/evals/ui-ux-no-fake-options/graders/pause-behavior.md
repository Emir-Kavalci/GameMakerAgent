PASS if the document describes both a main menu and a pause menu, shows how the player moves between them and the game, and says what happens to the game while the pause menu is open and when it closes (for example the game stops, the cursor appears, controls work again after resuming).
FAIL if one of the two menus is missing, or the pause menu's effect on the game is not described.
