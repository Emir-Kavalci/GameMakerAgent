The user brought in their design document and asked for improvement suggestions.
PASS if the final reply gives between one and five improvement suggestions, each with a short reason, and asks the user which ones (if any) they want. A suggestion may propose an answer to one of the open questions.
FAIL if it gives more than five suggestions, gives suggestions without any reason, says it already applied them to the GDD, or never asks the user which suggestions they want.
